Age Calculator - Years Until 120
A simple program that calculates how many years remain until reaching 120 years of age based on the user's current age.
📋 Description
This program takes the user's age as input and calculates the remaining years until they reach 120 years old. The result is displayed in a specific format that clearly shows the countdown to this milestone.
🎯 Challenge
The main objective of this challenge is to:

Receive the user's age as input
Calculate the difference between 120 and the current age
Display the result in the format: "X years till 120"

💡 Example
Input:
25
Output:
95 years till 120
